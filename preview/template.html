frederick

Parametric, 3D-printable accessories for the Lelit Fred (PL043MMI) grinder: an angled base and a single-dose hopper.

The 3D preview needs JavaScript and WebGL; the downloads below work without it.

Approximate grinder for context — not a measured model.

Download the STLs

All parts are in millimetres, already in print orientation. The grinder figures behind them are estimates: measure yours and rebuild if they differ.

Customise

Every dimension lives in config.py. Edit it, or override values for one build, then rebuild (Docker only, nothing to install):

make generate GEN_ARGS="--angle 12"
make generate GEN_ARGS="--set FOOT_D=22.0 --set THROAT_ID=34.2"
make site     # then open _site/index.html (or: make serve)
